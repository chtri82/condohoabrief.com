# Florida Condo & HOA Brief website

Static site for condohoabrief.com, published by Launchpad Digital L.L.C. Generated by `python3 tools/build.py` (no dependencies).

- `config.json` – site settings. `email` block: Brevo list id (3, "Condo & HOA Brief"), DOI template id, sender, reply-to, postal address, and the signup worker URL.
- Signup: `/subscribe/` and the signup boxes post to the Cloudflare worker (`/api/subscribe-brief`, in the launchpaddigitalfl.com repo `_lp-newsletter/`), which uses Brevo double opt-in into the Brief list. beehiiv is no longer used for signups.
- `tools/send_issue.py <slug>` – builds a Brevo campaign **draft** (never sends or schedules) from `content/issues/<slug>.html` using `tools/email/brief_issue.html`. Needs `BREVO_API_KEY` in the environment. `--preview out.html` renders without calling Brevo.
- `content/issues.json` + `content/issues/<slug>.html` – issues (imported from beehiiv; add new ones the same way). Remote images are downloaded into `assets/img/issues/<slug>/` at build time.
- `content/topics.json` – "Topics we cover" (summaries quoted from the issues).
- Output: `index.html`, `issues/`, `about/`, `sponsor/`, `subscribe/`, `feed.xml` (RSS), `sitemap.xml`.

Hosted on GitHub Pages at condohoabrief.com.
