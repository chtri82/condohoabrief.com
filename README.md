# Florida Condo & HOA Brief website

Static site for condohoabrief.com, published by Launchpad Digital L.L.C. Generated by `python3 tools/build.py` (no dependencies).

- `config.json` – site settings. **`subscribe_url` is the one place the signup link lives** (every Subscribe button goes to `/subscribe/`, which uses it). Switch it when we move off beehiiv.
- `content/issues.json` + `content/issues/<slug>.html` – issues (imported from beehiiv; add new ones the same way). Remote images are downloaded into `assets/img/issues/<slug>/` at build time.
- `content/topics.json` – "Topics we cover" (summaries quoted from the issues).
- Output: `index.html`, `issues/`, `about/`, `sponsor/`, `subscribe/`, `feed.xml` (RSS), `sitemap.xml`.

GitHub Pages and the custom domain are not enabled yet (pending approval).
